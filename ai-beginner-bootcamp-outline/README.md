# AgenticLabs.ng — AI Beginner Bootcamp

Welcome to the 5-Day AI Beginner Bootcamp repository. This course takes learners from passive users of AI to active directors of AI by building a **Universal Knowledge Worker**.

## 🚀 Course Goal
Over 5 days, participants build an autonomous AI agent capable of planning, web searching, summarizing, and presenting information. This prepares them for real-world AI automation tasks.

## 📂 Directory Structure

- **`day_1/`** to **`day_5/`**: The core materials for each day of the bootcamp.
  - `Day_X_Notebook.ipynb` - The interactive hands-on challenge for the participants.
  - `Day_X_Primer.md` - The theory and concepts needed for that day.
  - `Day_X_Slides.pptx` - Presentation slides for the instructor.
  - `Day_X_Transcript.md` - The video presentation script for the instructor.
- **`_archive/`**: Safely preserved older iterations of the course, alternative models, and experiments.
- **`_scripts/`**: Development and generation scripts for course maintainers.

## 🎓 5-Day Curriculum Arc

1. **Day 1: Hire the Brain**
   Introduction to autonomous agents and the Think-Act-Observe loop. Setting up Google AI Studio and defining the agent's core instructions.
2. **Day 2: Give it Hands**
   Connecting the agent to tools like Web Search so it can access real-time information rather than relying on static training data.
3. **Day 3: Give it Memory**
   Implementing conversation sessions so the agent can remember past interactions, preferences, and context over long tasks.
4. **Day 4: Quality Control**
   Introducing the temperature parameter, guardrails, and evaluating agent performance to ensure it doesn't fail in production.
5. **Day 5: Multi-Agent Teams**
   Creating a multi-agent system where a Manager, Researcher, and Writer collaborate to achieve a goal.
